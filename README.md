# TikTok Symphony workshop presentation

Open `index.html` in any modern browser. No build step or web server is required.

Controls:

- Left / Right arrows, Page Up / Page Down, or Space
- On-screen Previous / Next controls
- `O` opens the slide overview
- Home / End jump to the first / last slide
- Swipe and mouse-wheel navigation are supported
- Fullscreen is available from the top-right control

The deck is authored on a fixed 1920×1080 canvas and scales uniformly to any viewport.
